## Отчет по лабораторной работе Л06: Ansible Roles и Введение в CI

### 1. Цель работы
Изучение механизма ролей в Ansible для структурирования задач и повторного использования кода. Освоение шаблонов Jinja2 для динамической генерации конфигурационных файлов. Знакомство с основами Continuous Integration (CI) и настройка автоматических пайплайнов с помощью Github Actions.

### 2. Часть 1: Разработка роли Ansible для Nginx с виртуальными хостами
В ходе работы была создана роль nginx-vhosts, которая позволяет разворачивать веб-сервер с несколькими виртуальными сайтами.
Структура роли включает:

tasks/main.yml — основные задачи: установка Nginx, создание директорий для сайтов, копирование конфигов и index.html из шаблонов в цикле.

handlers/main.yml — хэндлер restart nginx, который срабатывает только при изменении конфигурационных файлов (обеспечивая идемпотентность).

templates/ — шаблоны Jinja2 (site.conf.j2 и index.html.j2), которые динамически подставляют имя сайта (переменную item) при генерации файлов.

Параметры сайтов (etis.com, fizfak.com, mehmat.ru) передаются в роль через переменную sites в главном плейбуке playbook.yml.

### 3. Проверка работы виртуальных хостов
После успешного применения роли, Nginx был перезапущен хэндлером. Для проверки маршрутизации запросов по доменным именам на одном IP-адресе (10.0.2.15) была использована утилита curl с подменой HTTP-заголовка Host. Все три виртуальных хоста вернули корректные, уникальные HTML-страницы.

### 4. Часть 2: Настройка непрерывной интеграции (CI) на GitHub Actions
Для автоматизации проверки кода проект был загружен в удаленный репозиторий на GitHub. В настройках репозитория были активированы Github Actions (выбрано Allow all actions and reusable workflows).

Был создан первый тестовый пайплайн devops_course_pipeline.yml, который запускается по событию push в ветку main. Пайплайн выполняет базовые команды на виртуальной машине GitHub (ubuntu-latest): вывод приветствия, проверку uptime, текущей директории (pwd) и имени пользователя (whoami). Пайплайн успешно прошел проверку.
